# Dependencias y avisos

Monitor de HS80 / HS80 Battery 1.2.1 es una aplicación independiente y no oficial. Corsair y HS80 son marcas de sus respectivos titulares.

El ejecutable utiliza estas dependencias:

| Componente | Versión de compilación | Licencia / fuente |
| --- | --- | --- |
| Python | 3.12.10 | PSF; https://www.python.org/ |
| Tcl/Tk | Incluido con Python | Sus licencias incluidas en el paquete de avisos |
| pystray | 0.19.5 | LGPLv3; https://github.com/moses-palmer/pystray |
| Pillow | 12.3.0 | MIT-CMU y avisos de sus bibliotecas; https://github.com/python-pillow/Pillow |
| hidapi (enlace Python y biblioteca HIDAPI) | 0.15.0 | Licencias BSD y avisos originales incluidos; https://github.com/trezor/cython-hidapi |
| PyInstaller | 6.22.3 | GPL con excepción para los programas empaquetados; https://pyinstaller.org/ |

La release incluye `AVISOS-LICENCIAS.zip` con los textos de licencia disponibles en el entorno de compilación y el paquete fuente original de pystray 0.19.5. Los componentes conservan sus licencias y derechos originales. No se incluyen DLL de Corsair ni una instalación de iCUE.

Esta publicación distribuye binarios y documentación; no declara que todo el monitor tenga una licencia de código abierto. Las licencias de terceros no otorgan derechos sobre las marcas ni cambian las condiciones de sus propios componentes.
